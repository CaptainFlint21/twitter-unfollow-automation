# Twitter Unfollow Automation
![Python](https://img.shields.io/badge/python-3.9%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-stable-success)

Автоматический скрипт для отписки от пользователей Twitter с защитой взаимных и верифицированных подписчиков.

## Возможности
- ✅ Автоматическая отписка
- ✅ (опционально) Верифицированные аккаунты пропускаются и добавляются в счетчик (по умолчаию вкл.)
- 🛡️ Защита взаимных подписчиков
- ⏸️ Автоматические паузы
- 📊 Статистика в реальном времени

## Использование

1. Открой Twitter в браузере
2. Перейди на страницу подписок
3. Открой консоль (F12 → Console)
4. Вставь код скрипта
5. Для остановки: `stopScript()`

## ⚠️ Рекомендации по безопасности
- PAUSE_AFTER	30-50	Имитирует поведение человека
- PAUSE_DURATION	5-10 минут	Снижает риск блокировки
- Общее время работы	Не более 2-3 часов подряд	Избегайте длительных сессий
- Совет : Запускайте скрипт в разное время суток и делайте перерывы между сессиями для максимальной безопасности.

```javascript
const TARGET_UNFOLLOWS = 200;      // Цель отписок (200)
const PAUSE_AFTER = 50;             // Пауза каждые N отписок
